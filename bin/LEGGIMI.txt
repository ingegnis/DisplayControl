FFmpeg is not bundled. Install via your OS package manager, place ffmpeg.exe here,
or set CARISMA_FFMPEG to its absolute path. Required encoders: libx264 and AAC;
libndi support is unnecessary. Python receives NDI and sends raw AV over loopback.

Verifica_NDI_Windows.bat can install the full distribution in bin/ffmpeg/;
executable: bin/ffmpeg/bin/ffmpeg.exe. Global PATH is unchanged; retain licenses.
